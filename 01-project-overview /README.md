## 📌 Quick Summary

The Vector platform is a web-based online learning and mock Interview tool. I provided end-to-end QA coverage during its initial development cycle:

- 200+ test cases across 5+ modules
- Daily collaboration with the developer through Jira
- Manual Testing on Chrome, Edge, and Firefox (Windows 11) 
- Full defect lifecycle management ( file → verify → close)
